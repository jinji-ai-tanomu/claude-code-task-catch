# タスク取りこぼし防止キット（Claude Code × Notion）

## これは何か

Claude Code との会話の中で出てきた「あとで自分がやること」を、Notion のタスク用データベースに自動で登録させる仕組みです。
Claude が登録し忘れても、応答の終わりに自動チェックが走って差し戻し、さらに1日1回、過去のログから取りこぼしを拾い直します。
入れるのは `bash install.sh` の1回だけで、外すときも `bash uninstall.sh` の1回です。

### 中身（3段構え）

| 段 | 何をするか | どのファイル |
|---|---|---|
| 1. 常設ルール | 会話でタスクが出たら、その場でNotionに入れるようClaudeに指示しておく | `claude-md/task-rule.md`（`~/.claude/CLAUDE.md` に追記） |
| 2. 応答ごとのチェック | Claude の応答が終わるたびに、直前のやりとりに「来週までに送る」のような言い回しがあるのにNotionに書き込んでいなければ、Claudeに差し戻して登録させる | `hooks/notion-task-catch.py`（Stop hook） |
| 3. 1日1回の回収 | その日最初に Claude Code を開いたとき、直近30時間のログからタスクらしき発言を洗い出し、未登録のものだけ追加させる。`/task-sweep` で手動でも実行できる | `hooks/notion-task-sweep-check.py`（SessionStart hook）、`hooks/notion-task-sweep.py`、`skills/task-sweep/` |

## 前提

- Claude Code が使えること（ターミナルで `claude` と打つと起動する状態）
- Claude Code から Notion に繋がっていること（Notion の MCP コネクタが接続済み。Claude Code で「Notionで◯◯を検索して」と頼んで結果が返ってくればOK）
- タスクを入れる Notion データベースが1つあること（下の「Notion DBの要件」を参照）
- Mac の場合、`python3` が使えること（入っていなければ install.sh が案内します）

## Notion DBの要件

タスク用データベースに、次のプロパティを用意してください。新しく作る場合はこの通りに、既存のDBを使う場合は**名前をこれに合わせて**ください。

| プロパティ名 | 種類 | 中身 |
|---|---|---|
| タスク名 | タイトル | 「見積書を取引先に送る」のような一文 |
| ステータス | ステータス | 「未着手」「進行中」「完了」の3つ |
| 期限 | 日付 | 会話の中で期限が出たときだけ入る |
| 完了日 | 日付 | 完了にしたときに入る |

プロジェクトごとにタスクを分けたい場合は、別に「プロジェクト」用のデータベースを作り、タスク用DBからリレーションでつないでおくと、Claude がわかる範囲でつないでくれます（なくても動きます）。

## collection ID（collection URL）の取り方

設定ファイルには、データベースの「collection URL」（`collection://` で始まる文字列）を書きます。Notion の画面上には出てこないので、Claude Code に聞いて調べます。

1. Notion でタスク用データベースを開き、右上の「…」→「リンクをコピー」でURLをコピーする
2. Claude Code を開いて、次のように頼む

   ```
   このNotionデータベースの collection URL を教えて: （コピーしたURLを貼る）
   ```

3. Claude が `notion-fetch` で調べて、`collection://xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx` のような文字列を返してくれます。これを控えておきます
4. プロジェクト用データベースを使う場合は、同じ手順でそちらの collection URL も控えます

## 導入手順

1. このリポジトリをダウンロードする（緑の「Code」ボタン →「Download ZIP」→ ダブルクリックで展開）
2. ターミナルを開き、展開したフォルダに移動する。`cd ` （cd と半角スペース）まで打ってから、フォルダをターミナルにドラッグ＆ドロップして Enter
3. 次を実行する

   ```
   bash install.sh
   ```

4. 最後に表示される案内に従って、`~/.claude/task-catch.config.json` を開いて書き換える。Finder で開く場合は、Finder で `Command + Shift + G` を押して `~/.claude` と入力すると見えます（テキストエディットで開けます）

   ```json
   {
     "notion_task_db": "collection://ここに控えたタスク用DBの文字列",
     "notion_project_db": "",
     "owner_name": "あなた",
     "extra_signals": [],
     "sweep_hours": 30
   }
   ```

   | 項目 | 必須 | 意味 |
   |---|---|---|
   | `notion_task_db` | 必須 | タスク用DBの collection URL。**ここが空のあいだは、キットは何もしません** |
   | `notion_project_db` | 任意 | プロジェクト用DBの collection URL。使わなければ空のまま |
   | `owner_name` | 任意 | あなたの呼び名（例: `"田中"`）。Claude への指示文の中で「田中本人が後でやること」のように使われます |
   | `extra_signals` | 任意 | タスクとして拾ってほしい自分の口癖を、正規表現で追加できます（例: `["ポチる", "やっつけ(る\|ないと)"]`） |
   | `sweep_hours` | 任意 | 1日1回の回収で、何時間前までのログを見るか（既定 30） |

5. Claude Code を開き直す（開いていたものは一度終了して、もう一度 `claude` で起動）

`install.sh` は何度実行しても大丈夫です。同じものを二重に登録せず、すでにある設定は消しません。実行前に `~/.claude/settings.json` と `~/.claude/CLAUDE.md` のバックアップ（`.bak-日時` 付き）を同じ場所に作ります。

## 動作確認

次のことが起きれば正常です。

1. **その日最初に Claude Code を開いたとき**、Claude が最初に「日次スイープ: 追加なし」（または「追加N件」とタスク名）と報告してから、あなたの用件に入る。2回目以降に開いたときは出ない
2. **会話の中で「この資料、来週までに先方に送らないと」のように言う**と、Claude が Notion にタスクを作って「Notionに追加: 資料を先方に送る」のように一行報告する
3. Claude が登録し忘れた場合でも、応答の最後に「タスクの取りこぼしを確認中」と表示されたあと、Claude がもう一度動いて登録するか「タスクなし」と返す
4. `/task-sweep` と打つと、手動で取りこぼしの回収が走る

何も起きない場合は、`~/.claude/task-catch.config.json` の `notion_task_db` が入っているか、書式（`"` や `,`）が崩れていないかを確認してください。設定が読めないとき、キットはエラーを出さずに黙って何もしない作りになっています。

ターミナルが使える方は、このフォルダで `bash tests/run.sh` を実行すると、本物の設定には触れずに一通りの動作確認ができます（最後に「失敗 0」と出れば正常）。

## よくある誤検知と対処

チェックは「タスクっぽい言い回しがあるか」を広めに見て、本当にタスクかどうかの判断は Claude に任せています。そのため、次のような場面で1回余分に Claude が動くことがあります（その場合 Claude は「タスクなし」とだけ返します）。

| よくある場面 | 理由 | 対処 |
|---|---|---|
| 「明日は雨らしいね」のような雑談 | 「明日」「来週」などの日付の言葉に反応する | 気にならなければそのままでOK（1ターン増えるだけ） |
| 「締切っていつだっけ？」のような質問 | 「締切」「期限」に反応する | 同上 |
| Claude に作業を頼んだだけ（「あとでこのファイル直しておいて」） | 「あとで」に反応する。Claude が会話中に終わらせた作業は登録されない | 同上 |
| 自分の口癖が拾われない（例:「ポチる」） | 標準の言い回しに入っていない | 設定の `extra_signals` に追加する |

それでもうるさい場合は、`~/.claude/hooks/task_signals.py` の `TASK_SIGNALS` から反応してほしくない言葉を消してください。一時的に止めたいだけなら、Claude Code で `/hooks` を開いて無効にできます。

## 外し方

このフォルダで次を実行します。

```
bash uninstall.sh
```

- `~/.claude/settings.json` から、このキットが足した2つのエントリだけを外します（他の設定には触りません。実行前にバックアップを作ります）
- コピーした hooks と `task-sweep` スキル、記録用のフォルダ `~/.claude/state/notion-task-catch/` を消します
- 設定ファイル `~/.claude/task-catch.config.json` は残します。消したい場合は `bash uninstall.sh --purge`
- `~/.claude/CLAUDE.md` に追記したルールは自動では消しません。ファイルを開いて `<!-- task-catch-kit:begin -->` から `<!-- task-catch-kit:end -->` までを手で消してください

## 既知の制限

- **言い回しの判定は日本語前提です。** 英語の会話では「deadline」「todo」くらいしか拾いません。英語で使う場合は `extra_signals` に足してください
- **最終判断は Claude 側です。** 拾った候補が本当にタスクか、すでに登録済みかは Claude が判断するので、まれに登録漏れや、似たタスクの二重登録が起きることがあります
- **チェックが何回働いたかは記録しません。** 記録しているのは「ログのどこまで見たか」と「今日の回収が済んだか」だけです
- 1日1回の回収は、Claude Code を開いたときに走ります。開かなかった日は走らず、次に開いた日にまとめて回収します（`sweep_hours` を長めにすると取りこぼしにくくなります）
- 同じ名前のファイル（`~/.claude/hooks/notion-task-catch.py` など、`~/.claude/skills/task-sweep/`）がすでにある場合は、`.bak-日時` を付けて退避してから上書きします
