# タスク取りこぼしスイープ

Stop hook がすり抜けたタスクを回収する。通常は1日1回 SessionStart hook が自動で
走らせるが、このコマンドで任意のタイミングでも実行できる。

## 手順

1. 候補を集める。引数で時間を指定されたらそれに従う（例:「今週ぶん」→ `--hours 168`）。
   指定が無ければ `--hours` を付けずに実行する（設定の `sweep_hours`、既定30時間が使われる）。

   ```
   python3 ~/.claude/hooks/notion-task-sweep.py
   ```

   出力の先頭に登録先DB（と、あればプロジェクトDB）の collection URL が出る。
   「設定が未完了です」と出たら、`~/.claude/task-catch.config.json` の `notion_task_db` を
   埋めるようユーザーに伝えて終わる。

2. 各候補について、**ユーザー本人が後で着手する必要がある事項か**を判断する。
   - Claudeがその場で完了させた作業は除外
   - 雑談・感想・調査結果の共有は除外
   - 所属する組織やチームの仕事でも、動くのが本人なら対象

3. 残ったものを、手順1で出た登録先DBの未完了タスクと突き合わせる。
   `notion-query-data-sources` で既存を取得してから、**未登録のものだけ**作成する。

4. 作成時のルール:
   - タイトルは動詞で終わる一文
   - 期限は会話中に明示されていたときだけ入れる。推測で埋めない
   - プロジェクトDBが出ていて、該当が分かればプロジェクトrelationを繋ぐ

5. 終わったらスタンプを更新する（自動スイープの二重実行を防ぐため）。

   ```
   mkdir -p ~/.claude/state/notion-task-catch && touch ~/.claude/state/notion-task-catch/last-sweep
   ```

6. 報告は「追加N件」＋タスク名の箇条書きだけ。除外した候補の一覧は出さない。
